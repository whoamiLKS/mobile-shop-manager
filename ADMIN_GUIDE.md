# Account guide / دليل الحساب

1. Open the website and choose **Create account / حساب جديد**. Use your real email, a password of at least eight characters and your shop name.
2. Confirm your email when required, then sign in. The account starts with an empty shop.
3. Use the same account on another phone or computer to load your cloud data.
4. Wait for **Saved to cloud ✓ / محفوظ سحابياً ✓** before closing. If a save fails, retry; a local pending copy remains in that browser. If another device changed the workspace, download your unsaved copy, load the cloud version and reapply only the missing changes.
5. Branches added inside your account share its login. Other independent owners should create separate email accounts. Adding a branch does not create a new user.
6. To transfer existing local data, sign in from the browser containing it and choose **Import old browser data / نقل البيانات القديمة**. This replaces the account’s workspace after confirmation; export an existing cloud backup first if needed.
7. JSON backup/import and CSV export remain available. Treat backups as confidential shop data. Import replaces the current account’s workspace.
8. **Lock / Sign out** signs this device out. The old `1234` PIN and demo shortcuts no longer log in. Password reset is available on the login screen.

Email confirmation requires the correct Supabase Site URL. External customer email delivery also requires production SMTP configuration; see README.md.
