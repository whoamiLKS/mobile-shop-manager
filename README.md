# Apex Mobile & Whish Agent - Manager Suite

A comprehensive, self-contained management suite and POS terminal designed for Lebanese mobile phone shops and authorized Whish Money agents.

## Features
- **Phone Inventory**: New & pre-owned device tracking with IMEI serials, battery health wear curves, and cosmetic grading.
- **Lebanese Telecom Vouchers**: Touch $, Touch Net, Alfa $, Alfa Ushare, Alfa Mobile Net, Ogero DSL, and gaming cards.
- **Whish Money Desk**: Customer cash-in, cash-out, float tracking, and agent commission ledger.
- **Phone Repairs**: Diagnostics, repair tickets, passcode tracking, spare parts cost, and technician labor margins.
- **POS Checkout & Trade-Ins**: Instant customer invoicing with dual currency valuation (USD & LBP) and thermal receipt printing.
- **Multi-Store SaaS**: Multi-branch support with PIN-protected terminal locking.
- **Built-in Smart Retail AI**: Instant trade-in appraisals, repair estimates, and daily manager audits without API keys.

## Fast Deployment Guide

### Option 1: GitHub Pages (Recommended — 100% Free Forever)
1. Push this repository to your GitHub account (see Git commands below).
2. On GitHub, go to your repository **Settings** &rarr; **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your website is live at `https://<your-username>.github.io/<repo-name>/`.

### Option 2: Vercel (1-Click Free Hosting)
1. Go to [vercel.com](https://vercel.com/) and sign in with GitHub.
2. Click **Add New...** &rarr; **Project**.
3. Select this repository and click **Deploy** (framework preset: "Other").
4. Your app is deployed with automatic SSL and a custom `.vercel.app` URL.

### Option 3: Netlify Drop (Instant Drag & Drop — No Git Required)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this project folder.
3. Your app goes live immediately.
